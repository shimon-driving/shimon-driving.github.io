# האתר של שמעון כרמונה – מורה לנהיגה

אתר תדמית סטטי שרץ ב-GitHub Pages בחינם. Jekyll הוא המנוע ש-GitHub Pages מפעיל בעצמו, כך שאין צורך בחשבון או בהתקנה נוספת. כל הקבצים (כולל אייקונים) נמצאים בתוך האתר. את התוכן עורכים דרך Pages CMS.

## מה יש בתיקייה

| קובץ / תיקייה | מה יש בו |
|---|---|
| `_data/home.yml` | כל הטקסטים בעמוד הבית |
| `_data/steps.yml` | שלבי "הדרך לרישיון" (כולל קישורים) |
| `_data/faq.yml` | שאלות ותשובות |
| `_data/reviews.yml` | המלצות. כל עוד הרשימה ריקה, האזור לא מופיע באתר |
| `_data/site.yml` | טלפון, וואטסאפ, רשתות חברתיות, לוגו ותיאור לגוגל |
| `accessibility.md` | הצהרת הנגישות |
| `robots.txt`, `llms.txt` | מאפשרים לגוגל ולכלי AI לסרוק את האתר. `llms.txt` נבנה אוטומטית מהתוכן |
| `assets/images/` | התמונות |
| `.pages.yml` | ההגדרות של טפסי העריכה ב-Pages CMS |
| `index.html`, `_layouts/`, `_includes/`, `assets/css/` | העיצוב והמבנה. לא נוגעים כדי לערוך תוכן |

## העלאה ל-GitHub (פעם אחת)

1. ב-GitHub פותחים ארגון (organization) בשם `shimon-driving`, ובתוכו repo ציבורי (**Public**) בשם `shimon-driving.github.io`.
2. **Add file → Upload files**: גוררים את כל התוכן של התיקייה הזו (לא את התיקייה עצמה) ולוחצים **Commit**.
   קבצים שמתחילים בנקודה (`.pages.yml`) לפעמים מוסתרים במחשב. כדאי לוודא שגם הוא עלה.
3. **Settings → Pages**: תחת *Source* בוחרים **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`, ולוחצים **Save**.
4. אחרי דקה-שתיים האתר יעלה בכתובת `https://shimon-driving.github.io`. אפשר לעקוב בלשונית **Actions**.

אם האתר יושב בשם אחר, מעדכנים את `url` ב-`_config.yml` בהתאם.

## גוגל וכלי AI

- `robots.txt` מתיר לכל מנועי החיפוש ולכלי ה-AI לסרוק את האתר.
- `sitemap.xml` נוצר אוטומטית.
- `llms.txt` הוא סיכום של כל התוכן בשביל כלי AI, והוא מתעדכן לבד מהתוכן באתר.
- בקוד יש נתונים מובנים (schema.org) על העסק ועל השאלות והתשובות, שעוזרים לגוגל להציג אותם בתוצאות.
- אחרי העלייה כדאי להוסיף את האתר ל-[Google Search Console](https://search.google.com/search-console) ולשלוח שם את `sitemap.xml`.

## חיבור דומיין (כשיהיה)

1. **Settings → Pages → Custom domain**: מקלידים את הדומיין ושומרים.
2. אצל רשם הדומיין מגדירים רשומות DNS לפי ההוראות של GitHub.
3. ב-`_config.yml` משנים את `url:` לכתובת הדומיין (למשל `"https://www.example.co.il"`).
4. מסמנים **Enforce HTTPS**.

## עריכת תוכן ב-Pages CMS

1. נכנסים ל-[app.pagescms.org](https://app.pagescms.org) ומתחברים עם חשבון ה-GitHub.
2. בוחרים את ה-repo. בתפריט מופיעים: שאלות ותשובות, הדרך לרישיון, המלצות, טקסטים בעמוד הבית, פרטים כלליים, הצהרת נגישות.
3. עורכים ולוחצים **Save**. האתר מתעדכן אוטומטית תוך דקה-שתיים.

תמונות מעלים דרך שדה התמונה בטופס, והן נשמרות ב-`assets/images`.

## הערות

- הכותרת הראשית בנויה משתי שורות: שורה 1 בלבן, שורה 2 בצהוב.
- המספור של השלבים אוטומטי לפי הסדר. אם מזיזים שלב, המספרים מתעדכנים לבד.
- לכל שלב אפשר להוסיף כמה קישורים שרוצים, או אף אחד.
- את השאלה הראשונה האתר מציג פתוחה, וכל השאר סגורות.
